= Pontos de extremidade de certificado da API Astra (ACC)
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Gerencie os certificados confiáveis do administrador que o Astra Control usa para estabelecer conexões de saída.

A API do aplicativo de certificados representa certificados confiáveis pelo administrador que são usados para estabelecer conexões de saída.
