= Excluir uma assinatura
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Exclui uma assinatura, removendo o recurso especificado da API de assinatura, juntamente com todas as cobranças associadas.



[[http-method-and-endpoint]]
== Método e endpoint HTTP

[.api-doc-operation .api-doc-operation-delete]#EXCLUIR# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/subscriptions/{subscription_id}`#



[[usage-notes]]
== Notas de utilização

Remove o recurso Subscription API especificado.

*Efeitos Colaterais*

* A assinatura é excluída juntamente com todas as cobranças associadas a ela.

== Parâmetros

[cols="5*"]

| Nome | Tipo | Em | Obrigatório | Descrição

* exemplo: {{.Account}}




| id_da_assinatura | string | caminho | Verdadeiro  a| 
ID da coleção de assinaturas a ser listada

|===
